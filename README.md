# 편입수학 트레이너

ChatGPT와의 편입수학 학습 대화에서 확인한 이해도와 Notion의 `편입 수학 앱 학습 소스`를 기반으로, 막힌 사고 단계부터 다시 가르치는 적응형 PWA입니다.

- 앱: https://jiyeong-kor.github.io/transfer-math-trainer/
- 기준 데이터: Notion `편입 수학 앱 학습 소스`
- 구현 기획: Notion `편입 수학 트레이너 커리큘럼·구현 기획`

## 학습 범위

현재 앱은 **7단계 커리큘럼, 74개 micro concept, 77개 학습·진단 문제**를 포함합니다.

1. 선행 개념 진단
2. 미분학Ⅰ
3. 적분학Ⅰ
4. 미적분학Ⅱ
5. 선형대수학
6. 공업수학
7. 학교별 실전 준비

학교별 실전 단계는 2027학년도 최종 모집요강과 실제 기출 범위가 확정되는 대로 학교 태그와 실전 세트를 추가하는 확장 지점으로 둡니다.

## 적응형 학습 방식

### 오늘의 3블록

매일 현재 이해 상태를 기준으로 세 종류를 구성합니다.

- **약점 복구**: `재학습 필요` 또는 `부분 이해` 개념
- **진도 연결**: 현재 진도를 막는 선행 개념 또는 다음 미평가 개념
- **간격 복습**: 이전에 이해한 개념의 독립 재확인

기본 3블록을 완료한 뒤에는 최신 숙련도를 반영하여 **추가 3블록**을 다시 계산할 수 있습니다.

### 선행 개념 그래프

상위 문제에서 막히면 무조건 해당 단원 전체를 다시 공부하지 않습니다. 필요한 선행 micro concept만 찾아서 먼저 복구합니다.

예를 들어 ε-δ는 다음처럼 분리합니다.

`δ가 통제하는 대상 → 목표식 인수분해 → 통제되지 않는 인자 찾기 → 근방 제한으로 상한 만들기 → ε 조건으로 δ 계산 → min으로 조건 결합`

현재 초기 학습 상태에서는 이미 이해한 앞 단계는 유지하고, `근방 제한으로 상한 만들기`와 `min으로 조건 결합하기`를 실제 약점으로 우선합니다.

## 숙련도와 오답 분류

개념별 상태는 다음과 같습니다.

`미학습 → 미평가 → 재학습 필요 → 부분 이해 → 이해 확인 → 안정`

앱은 정오답뿐 아니라 자기 평가와 오답 원인을 함께 저장합니다.

- 개념 자체를 모름
- 논리 연결 실패
- 공식·조건 기억 실패
- 계산 오류
- 조건 해석 오류
- 단순 실수

이미 안정된 개념에서 단순 계산 실수 한 번이 발생했다고 해서 개념 전체를 즉시 재학습 상태로 내리지 않습니다.

## 주요 기능

- 모바일 우선 PWA
- 서울 날짜 기준 일일 학습 계획
- 학습 세션 중단 후 이어하기
- 과목별 개념 숙련도와 진행률
- 약점 개념 필터
- ε-δ 집중 복구 모드
- 정답 해설과 단계별 풀이
- JSON 학습 기록 백업·복원
- 서비스 워커 기반 오프라인 실행
- 새 콘텐츠를 기존 기록과 합치는 상태 마이그레이션

## 검증

모든 `main` 푸시와 PR에서 GitHub Actions가 다음을 검사합니다.

- 모든 JavaScript 파일 구문
- 개념 ID와 커리큘럼 순서 중복
- 선행 개념 참조와 순환 관계
- 모든 개념의 설명 존재 여부
- 모든 개념의 연결 문제 존재 여부
- 문제 정답과 선택지의 일관성
- HTML과 서비스 워커의 콘텐츠 파일 연결
- 오늘의 3블록 생성
- 숙련도 승급·강등과 단순 실수 예외

로컬에서도 다음 명령으로 확인할 수 있습니다.

```bash
node scripts/validate-data.mjs
node scripts/test-core.mjs
```

## 데이터 원칙

교재 페이지를 끝냈다는 사실만으로 개념을 이해했다고 판정하지 않습니다. ChatGPT 학습 대화에서 실제로 확인한 이해, 오개념, 반복 오류와 앱 내 문제풀이 결과를 별도로 누적합니다.

저작권이 있는 교재 원문이나 기출문제를 그대로 복제하지 않고, 개인 학습 과정에서 정리한 개념과 새로 구성한 진단·연습 문항을 사용합니다.
