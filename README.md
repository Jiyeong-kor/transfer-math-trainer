# 편입수학 트레이너

ChatGPT와의 편입수학 학습 대화에서 확인한 이해도와 Notion의 `편입 수학 앱 학습 소스`를 기반으로, 약한 개념부터 다시 가르치는 개인용 PWA입니다.

## 목표

단순 문제은행이 아니라 `어디에서 사고가 끊겼는지`를 micro concept 단위로 추적합니다.

- 선행 개념 진단
- 미분학Ⅰ → 적분학Ⅰ → 미적분학Ⅱ → 선형대수학 → 공업수학 → 학교별 실전
- 정오답, 오답 원인, 자기 평가를 함께 저장
- `재학습 필요 → 부분 이해 → 이해 확인 → 안정`으로 숙련도 관리
- 오늘의 3블록: 약점 복구 / 새 진도 / 간격 복습
- 선행 개념이 부족하면 자동으로 하위 개념을 우선
- JSON 백업·복원
- 서비스 워커 기반 오프라인 실행

## 초기 학습 데이터

첫 버전은 실제 대화에서 이해 상태가 확인된 ε-δ 개념을 가장 세밀하게 제공합니다.

- `|x-a| < δ`가 의미하는 것
- 목표식 인수분해
- 통제되지 않는 인자 찾기
- x의 근방 제한으로 상한 만들기
- ε 조건에서 δ 계산하기
- 여러 δ 조건을 `min`으로 결합하기

이후 미분학Ⅰ의 다음 진도와 적분학Ⅰ, 미적분학Ⅱ, 선형대수학, 공업수학 진단용 개념을 포함합니다.

## 실행

정적 웹 서버에서 저장소 루트를 제공합니다.

```bash
npx serve .
```

데이터 검증은 다음 명령으로 실행합니다.

```bash
node scripts/validate-data.mjs
```

## 데이터 원칙

교재 페이지를 끝냈다는 사실만으로 개념을 이해했다고 판정하지 않습니다. ChatGPT 학습 대화에서 실제로 확인한 이해, 오개념, 반복 오류와 앱 내 문제풀이 결과를 별도로 누적합니다.

저작권이 있는 교재 원문이나 문제를 그대로 공개하지 않고, 개인 학습을 위해 재구성한 개념·진단 문항을 사용합니다.
